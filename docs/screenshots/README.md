# Portfolio screenshots

PNG files are not generated by the application. Capture them locally in a desktop browser after `npm run dev`, with sample catalogue data (seed) and a signed-in customer plus an admin account.

Place files in this folder using the names below. The root README links here until images exist.

## storefront-home.png

**Capture:** `/`  
**Show:** Header, featured categories, latest products, footer.  
**Demonstrates:** Storefront layout and catalogue entry points.

## product-catalogue.png

**Capture:** `/shop` with at least one filter or search applied.  
**Show:** Product grid, filters, sort, pagination or empty-state if filters exclude everything.  
**Demonstrates:** Search and filter UX.

## cart.png

**Capture:** `/cart` with at least one line item while logged in.  
**Show:** Quantities, line totals, subtotal, checkout action.  
**Demonstrates:** Authenticated cart (server-calculated money).

## checkout.png

**Capture:** `/checkout` with a saved address selected.  
**Show:** Address choice, optional promotion field, order summary, and the note that payment is not collected.  
**Demonstrates:** Demo checkout without a payment gateway.

## account-orders.png

**Capture:** `/orders` after at least one `PENDING` order.  
**Show:** Order number, status, operational total, link to detail.  
**Demonstrates:** Customer order history.

## admin-dashboard.png

**Capture:** `/admin` as `ADMIN`.  
**Show:** Count cards and recent orders.  
**Demonstrates:** Role-gated operations overview.

## admin-products.png

**Capture:** `/admin/products`.  
**Show:** Product list, archive/active state, actions to add or edit.  
**Demonstrates:** Catalogue administration.

## admin-inventory.png

**Capture:** `/admin/inventory`.  
**Show:** Stock status badges (healthy / low / out of stock) and filters.  
**Demonstrates:** Inventory overview.

## admin-inventory-detail.png

**Capture:** `/admin/inventory/:productId` for a product with movements.  
**Show:** Current quantity, receive/adjust controls, movement history.  
**Demonstrates:** Ledger-style stock changes.

## admin-promotions.png

**Capture:** `/admin/promotions` with at least one code.  
**Show:** Code, derived status (active / upcoming / expired / disabled), discount summary.  
**Demonstrates:** Promotion operations.

## admin-analytics.png

**Capture:** `/admin/analytics?range=30d`.  
**Show:** Summary cards, at least one chart, and the operational-order-value clarification.  
**Demonstrates:** Admin analytics (not payment revenue).
